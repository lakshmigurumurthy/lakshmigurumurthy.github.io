01

Enterprise AI · Agentforce

Making conversational memory understandable

The technical challenge. Agent memory spans several distinct concepts: what an agent remembers, how preferences and controls work, which experiences support memory, and how users manage stored information. A single broad explanation isn't enough for administrators trying to configure the feature.

Audience
Salesforce administrators and people configuring Agentforce experiences
Content focus
Conceptual guidance, setup paths, supported experiences, user controls, and memory management actions
My work
Developing and updating Help and release content, clarifying behavior with product and engineering partners, and aligning guidance with supported functionality
Writing principle

Start with what the feature does, distinguish administrator setup from end-user control, and organize instructions around the task a reader is trying to complete.

02

AI actions · Technical reference

Turning action behavior into usable reference content

The technical challenge. An action reference needs precision. Readers need to understand supported inputs and outputs, file formats, limits, and configuration details without searching through a narrative explanation.

Audience
Administrators and builders configuring standard actions
Content focus
Speech-to-text, text-to-speech, web search, and action configuration considerations
My work
Creating and maintaining action reference content, documenting parameters and limits, and checking technical details with engineering partners
Writing principle

Put the decision-critical information where the reader expects it: supported inputs, expected outputs, constraints, and relevant considerations.

Explore the Speech to Text action reference ↗
03

Conversational AI · Messaging

Explaining a cross-channel voice experience

The technical challenge. Messaging features connect setup, channel behavior, user expectations, and troubleshooting. Clear documentation has to help administrators understand both how to configure the experience and what happens when customers interact with it.

Audience
Administrators setting up messaging and agent experiences
Content focus
WhatsApp voice message setup, supported languages, and troubleshooting
My work
Partnering with product and engineering teams on feature guidance and release communication, with publication aligned to launch readiness
Writing principle

Connect configuration steps to expected user behavior, and separate prerequisites, setup, and troubleshooting so readers can quickly find their next action.
